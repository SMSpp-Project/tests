# Cross-check BlockSolverConfig for a MIXED-binary BinaryKnapsackBlock (some
# continuous variables): attaches every solver that handles continuous
# variables and must give the SAME optimal value: the :MILPSolver (the exact
# reference), the two exact dynamic programs (full-table DPBinaryKnapsackSolver
# and core CoreDPBinaryKnapsackSolver), and the greedy relaxation in both its
# from-scratch and incremental flavours, whose true bounds must BRACKET that
# optimum (see SolveAll() in test.cpp). The BranchAndXSolver is NOT here: it
# branches on binary variables, so it only applies to pure-binary instances
# (see BSPar.txt); the incremental greedy is attached as a standalone
# relaxation, the same role its from-scratch sibling plays here.
#
# The per-solver ComputeConfig are factored into the *Cfg.txt fragments shared
# with BSPar.txt (included via '*'), so there is no duplicated configuration.
#
