# Cross-check BlockSolverConfig for a MIXED-binary BinaryKnapsackBlock (some
# continuous variables): attaches every solver that handles continuous
# variables and must give the SAME optimal value, i.e., the :MILPSolver (the
# exact reference) and the core CoreDPBinaryKnapsackSolver, plus the Greedy
# relaxation, whose true bounds must BRACKET that optimum (see SolveAll() in
# test.cpp). The full-table DPBinaryKnapsackSolver is kept but disabled (the
# core DP subsumes it), exactly as in BSPar.txt. The BranchAndXSolver is NOT
# here: it branches on binary variables, so it only applies to pure-binary
# instances (see BSPar.txt).
#
# The per-solver ComputeConfig are factored into the *Cfg.txt fragments shared
# with BSPar.txt (included via '*'), so there is no duplicated configuration.
