# A txt description of a BlockSolverConfig for a MMCFBlock to be solved by
# two different Solver: a :MILPSolver and a LagrangianDualSolver using a
# BundleSolverML (the ML-based BundleSolver that predicts the step-size t
# with a neural network) as the inner Solver.
#
# It is the ML counterpart of BSPar.txt: it reuses the same LDCfg.txt base
# and the same (flow) relaxation as BSPar.txt, so that the Lagrangian dual
# bound matches the reference, and only overrides, via the cascade-override
# mechanism, the entries that make the inner Solver a self-training
# BundleSolverML driving t with the network (str_LDSlv_ISName, the
# network-friendly t-strategy parameters, intMLTrainOnline / intMLSeed /
# intNTrainRounds).
#
#   Enrico Gorgone, Antonio Frangioni, Donato Meoli
