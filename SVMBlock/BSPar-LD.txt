# A txt description of a BlockSolverConfig for the Block that
# make_consensus_Block() assembles, i.e., the training problem written as one
# problem per chunk tied by consensus constraints, to be solved by two
# different Solver: a :MILPSolver, which flattens the whole tree and therefore
# solves the rewriting as a whole, and a LagrangianDualSolver, which relaxes
# the consensus constraints and solves the Lagrangian dual with a
# BundleSolver, each subproblem being the SVM of one chunk. Note that
# SMOSolver is not among them: it only attaches to a SVMBlock, while the
# assembled Block is not one
