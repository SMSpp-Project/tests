# BlockSolverConfig for a MultiKnapsackAssignBlock, registering the three
# Solver to be cross-checked:
#
#   - :MILPSolver            the abstract representation of the whole tree

#   - LagrangianDualSolver   the constraints linking the BinaryKnapsackBlock
#                            relaxed, the Lagrangian dual solved by a

#   - LagrangianDualSolver   the same Lagrangian dual, solved by a
#                            SubGradSolver (LDCfg-SG.txt)
#
# The problem being an integer one, the Lagrangian dual is a relaxation of it
# and the battery declares it so (-R ,r,r).

*MILPCfg.txt          # ComputeConfig of the :MILPSolver
