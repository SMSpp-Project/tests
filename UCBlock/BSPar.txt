#
# Cross-check BlockSolverConfig for a UCBlock: it attaches every Solver that
# must agree on the optimum, so that a single sweep cross-checks them all
# (see the batches):
#
#   - :MILPSolver           exact MIP, the reference optimum
#   - LagrangianDualSolver  exact too on these instances (it closes the gap),
#                           using a BundleSolver as the inner Solver
#   - PrimalProximalHeur    a heuristic: it only UPPER bounds the optimum
#
# The test reads each Solver as the [ get_lb() , get_ub() ] interval of the
# base Solver contract, with the per-Solver optimality tolerances declared in
# the tester positionally on this very Solver list (the two exact ones first,
# the heuristic third), so adding an exact Solver here is all it takes to
# bring it into the cross-check. The per-Solver ComputeConfig are factored
# into the *Cfg.txt fragments. BSPar-EASY.txt and
# BSPar-AC.txt are the variants for the instances whose components are all
# "easy" for BundleSolver (intDoEasy=0), the AC one also tuned for the QCP
# ThermalUnitBlock; BSPar-MILP.txt solves with the :MILPSolver alone. See the
# batches for which is used where.
# NOTE: an overriding ComputeConfig that is not the last in the list must end
# with the '*' extra-Configuration pointer, or the parser runs into the next.
#
#   Enrico Gorgone, Antonio Frangioni, Donato Meoli
#
# - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
# - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
