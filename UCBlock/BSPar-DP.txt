# Cross-check BlockSolverConfig for a UCBlock in which the Lagrangian Dual is
# the one of the original problem: the sub-Block of the LagBFunctions are
# solved exactly by the dynamic programming Solver [see InnerBSCfg-DP.txt],
# and the :MILPSolver solves the MIP rather than its continuous relaxation
# [see MILPCfg-MIP.txt], so that the three Solver speak about the same
# problem. It attaches:
#
#   - :MILPSolver           exact MIP, the optimum
#   - LagrangianDualSolver  a relaxation: with the sub-problems solved
#                           exactly its bound is the Lagrangian one, which
#                           has a duality gap, so a batch running this must
#                           declare it with -E ,inf instead of holding it to
#                           its dblRelAcc
#   - PrimalProximalHeur    a heuristic: it brackets the optimum between the
#                           bound of its unpenalized iteration and the best
#                           feasible solution it finds
#
# The point of solving the sub-problems exactly is that the proximal penalty
# of the heuristic acts on the binary variables of the sub-problems: with
# the continuous relaxation there they are not binary, the penalized
# Lagrangian Dual does not converge, and the heuristic spends its whole
# budget in one call.
#
#   Enrico Gorgone, Antonio Frangioni, Donato Meoli
#
# NOTE: an overriding ComputeConfig that is not the last in the list must end
# with the '*' extra-Configuration pointer, or the parser runs into the next.
#
#   Enrico Gorgone, Antonio Frangioni, Donato Meoli
#
