#
# BlockSolverConfig for a GeneralizedAssignmentBlock, registering the
# eighteen Solver to be cross-checked:
#
#   - :MILPSolver            the abstract representation of the whole tree
#                            (MILPCfg.txt)
#   - LagrangianDualSolver   the constraints linking the BinaryKnapsackBlock
#                            relaxed, the Lagrangian dual solved by a
#                            BundleSolver (LDCfg.txt)
#   - LagrangianDualSolver   the same Lagrangian dual, solved by a
#                            SubGradSolver (LDCfg-SG.txt)
#   - RepairGeneralizedAssignmentSolver
#                            the repair heuristic, guided by the point the
#                            Variables hold (RepairCfg.txt)
#   - PrimalProximalHeur     the proximal heuristic on the same Lagrangian
#                            dual, the repair heuristic as its primal
#                            recovery (PPHCfg.txt)
#   - BranchAndXSolver       the Lagrangian dual of the nodes, the same
#                            heuristic at each of them (BXCfg.txt)
#   - BranchAndXSolver       the same, by the cutoff probing with targets
#                            1 apart from the bound of the root, fixing by
#                            Lagrangian reduced cost against them
#                            (InnerBSCfg-LD-fix.txt)
#   - BranchAndXSolver       the same, with the bundle kept from one node to
#                            the next (BXCfg-keep.txt), with the heuristic
#                            at the root and down to depth 2 only
#                            (BXCfg-depth.txt), at the root and close to
#                            the best bound only (BXCfg-gap.txt), with the
#                            incumbent read again during the dual of a node
#                            (BXCfg-reread.txt) and with the incumbent as
#                            the cutoff of the recovery (BXCfg-reccut.txt)
#   - BranchAndXSolver       the same, with the reliability branching of
#                            strong branching (BXCfg-reliab.txt) and of the
#                            fixing penalties (BXCfg-relpen.txt), with the
#                            bounds of the children from the penalties
#                            (BXCfg-bound.txt), and by best-first with dives
#                            within a quarter of the gap (BXCfg-plunge.txt)
#   - BranchAndXSolver       the same, with the bounds of the children and
#                            the Lagrangian dual of the nodes stopped after
#                            30 iterations (BXCfg-stop.txt)
#   - BranchAndXSolver       the same, with the reliability branching of
#                            strong branching whose trials have 20
#                            iterations each (BXCfg-reliter.txt)
#
# The problem being an integer one, the Lagrangian dual is a relaxation of it
# and the battery declares it so (-R ,r,r).
#
