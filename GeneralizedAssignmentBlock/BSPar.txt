# BlockSolverConfig for a GeneralizedAssignmentBlock, registering the seven
# Solver to be cross-checked:
#
#   - :MILPSolver            the abstract representation of the whole tree
#                            (MILPCfg.txt)
#   - LagrangianDualSolver   the constraints linking the BinaryKnapsackBlock
#                            relaxed, the Lagrangian dual solved by a
#                            BundleSolver (LDCfg.txt)
#   - LagrangianDualSolver   the same Lagrangian dual, solved by a
#                            SubGradSolver (LDCfg-SG.txt)
#   - RepairGeneralizedAssignmentSolver
#                            the repair heuristic, guided by the point the
#                            Variables hold (RepairCfg.txt)
#   - PrimalProximalHeur     the proximal heuristic on the same Lagrangian
#                            dual, the repair heuristic as its primal
#                            recovery (PPHCfg.txt)
#   - BranchAndXSolver       the Lagrangian dual of the nodes, the same
#                            heuristic at each of them (BXCfg.txt)
#   - BranchAndXSolver       the same, by the cutoff probing with targets
#                            1 apart from the bound of the root, fixing by
#                            Lagrangian reduced cost against them
#                            (InnerBSCfg-LD-fix.txt)
#
# The problem being an integer one, the Lagrangian dual is a relaxation of it
# and the battery declares it so (-R ,r,r).
#
# - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
